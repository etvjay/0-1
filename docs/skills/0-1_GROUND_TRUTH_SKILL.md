# 0-1 Ground Truth Skill

## Mission

Maintain the smallest factual description of what 0-1 currently does and what remains target/unverified.

Promote only when implementation + tests + negative tests + review + required runtime evidence exist.

Do not promote target architecture because docs exist, call shadow results live execution, call an ACK a profitable outcome, erase contradictions, silently change product invariants, or convert assumptions into facts.

Truth classes: `CANONICAL`, `IMPLEMENTED_LOCAL`, `SHADOW_VERIFIED`, `LIVE_VERIFIED`, `UNVERIFIED`, `ASSUMPTION`, `CONTRADICTED`, `BLOCKED`, `NOT_CLAIMED`.
