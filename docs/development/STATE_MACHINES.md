# 0-1 Binance State Machines

## Opportunity

```text
DISCOVERED → RESEARCHING → COUNCIL_REVIEW
→ THESIS_ACCEPTED | THESIS_REFUSED
→ MANDATE_ISSUED → MANDATE_ARMED → EXECUTING
→ FILLED | REFUSED | INVALIDATED | EXPIRED | FAILED
```

## Mandate runtime

```text
ARMED → TRIGGERED → VALIDATING → SUBMITTING → ACKNOWLEDGED → PARTIALLY_FILLED → FILLED
```

Side/terminal transitions:

```text
ARMED → EXPIRED | SUPERSEDED | INVALIDATED
TRIGGERED → INVALIDATED
VALIDATING → REFUSED
SUBMITTING → FAILED | UNKNOWN
ACKNOWLEDGED → CANCELLED
PARTIALLY_FILLED → FILLED | CANCELLED
```

## Development change

```text
DISCOVERED → PROPOSED → REVIEWING → APPROVED → IMPLEMENTING
→ IMPLEMENTED_LOCAL → TESTING → EVIDENCED → REVIEWED → INTEGRATED
```

Failure branches: `BLOCKED`, `REJECTED`, `REVERTED`, `DEPRECATED`.
